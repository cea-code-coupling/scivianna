##   Graph example

In this example, a graph of 2D plots (a lattice, a hex ring, a bar and a result lattice) connected by directed links is displayed as an interactive ReactFlow canvas.

The nodes can be dragged individually, rotated (the hex ring is pre-rotated), selected in groups by dragging an empty area of the canvas, and plugged on any side: each link declares the side it attaches to on both endpoints. Hovering a node figure shows the cell value, as in the 2D panels.
