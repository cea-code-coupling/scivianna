## VTK 3D Example

This example demonstrates the visualization of VTK file formats in Scivianna, including both 2D slice and 3D geometry display.

### Features

- **3D Unstructured Grid Visualization**: Display 3D mesh geometry with field values
- **2D Slice Extraction**: Interactive cross-section viewing with pan/zoom
- **Time-Dependent Data**: Support for time-varying simulations via `.pvd` files
- **Multiple VTK Formats**: Support for `.vtu`, `.vtp`, `.pvd`, and other VTK formats
